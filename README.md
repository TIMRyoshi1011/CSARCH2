## Case Project #2: Computing Machine

### Machine 2: Binary 32-bit Floating-Point Machine  

Process: IEEE 754 binary single-precision operations.  

**1. Convert decimal to binary single-precision**  
&emsp; **a. Input:** A decimal number.  
&emsp; **b. Output:** The IEEE 754 single-precision representation (including special cases like NaN, Infinity, etc.) in:  
&emsp; &emsp; o &emsp;i) Binary with proper spacing  
&emsp; &emsp; o &emsp;ii) Hexadecimal  

**2. Demonstrate rounding methods**  
&emsp; **a. Input:** A number in either decimal or binary format.   
&emsp; **b. Input:** The target number of digits (or bits) for rounding.   
&emsp; **c. Output:** The rounded results using all four methods: chopping (truncation), round-up, round-down, and
round-to-nearest ties-to-even.    

**3. Perform arithmetic operations (addition and multiplication) using rounding method**  
&emsp; **a. Input:** Operands in either decimal or IEEE hexadecimal format    
&emsp; **b. Input:** The type of operation (addition or multiplication).  
&emsp; **c. Output:** The step-by-step solution and final result (including special cases) in:  
&emsp; &emsp; &emsp;i) Binary with proper spacing  
&emsp; &emsp; &emsp;ii) Hexadecimal  
&emsp; &emsp; &emsp;iii) Decimal
